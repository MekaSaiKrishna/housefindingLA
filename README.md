# housefindingLA

A tool to help find housing in Los Angeles.

## Overview

This project assists users in searching for and evaluating rental or purchase properties in the Los Angeles area.

## Features

- Search for available properties in LA neighborhoods
- Filter by price, size, and location
- Compare listings side by side
